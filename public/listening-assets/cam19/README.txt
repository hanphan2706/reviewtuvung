# Thư mục audio pilot (Cam 19, v.v.)

- Copy từ zip các file đầy đủ theo tên gốc, ví dụ: `Test1 Part1.mp3` … `Test1 Part4.mp3`.
- **Intro ngắn (tuỳ chọn):** cắt/export khoảng 10–30 giây đầu (hoặc đoạn “mở bài” không spoil), đặt tên đúng với manifest — pilot dùng `Test1-intro.mp3` (xem `introAudioPublicPath` trong `lib/listening/content-manifest.ts`). App **không** tự cắt MP3 trong repo.
- Các file `.mp3` ở đây được `.gitignore` — không lên Git công khai.
