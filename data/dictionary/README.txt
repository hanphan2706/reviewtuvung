en-vi-wiktionary.json — chỉ mục nghĩa VI trích từ EN Wiktionary (import offline).

Cập nhật:
  npm run dictionary:import-vi          # ~40 từ học thuật + bài đọc hub
  npm run dictionary:import-vi:all      # thêm token từ hub (chậm hơn)
  npm run dictionary:import-vi -- --words path/to/extra-words.txt

Sau khi import, restart dev server để nạp lại file JSON.
